# Reproduction guide

## Scope

This release preserves research scripts without changing optimization equations, fitting logic or experimental splits. Inputs and outputs are excluded. A local source manifest maps the copied files to their original archive paths. The release changes the hardcoded EIA credential to an environment variable and normalizes text encoding/line endings.

## Working directory

Run pipeline commands **from `pipeline/`**. Many scripts use current-directory defaults; others use the directory containing the script. Moving individual scripts can break local imports and relative paths. Run variants from their own directory and consult their bundled README. Do not overwrite the primary generators with a variant without recording that change.

## Archived pipeline

1. Inspect `python ../tools/download_nyiso_ev_data.py --help` for supported sources. Obtain data through the provider and retain its provenance and terms.
2. Inspect the dataclass configuration in `build_ev_dataset.py` and `build_grid_dataset.py` and place the required source files accordingly. The grid builder expects `raw/load/*isolf.csv`, `raw/price/*damlbmp_zone.csv`, and `raw/emission/*dam_imer.csv`.
3. Run `python build_ev_dataset.py` and `python build_grid_dataset.py` after configuring those paths.
4. Run `python train_ev_generator.py` and `python train_grid_generator.py` to fit the archived generators, then `python build_joint_scenarios.py`.
5. Inspect configurations in `build_stress_scenarios.py` and `build_optimization_inputs.py` before building each named stress group. Defaults do not automatically execute every manuscript arm.
6. Optimization entry points include `run_stochastic_scenario_optimization_with_degradation.py`, `run_stochastic_scenario_optimization_with_degradation_pinn.py` and `run_receding_horizon_optimization.py`. Select the model and inputs explicitly.

The primary `train_ev_generator.py` uses empirical counts and Gaussian mixtures. Neural CVAE/diffusion variants are supplied separately. Their presence does not mean the archived scenarios were generated by those variants.

## Section IV archive replay

`run_section_iv_replay.py` expects four directories beside the script:

```text
optimization_inputs_joint/
optimization_inputs_evening_peak_cluster/
optimization_inputs_sustained_high_price/
optimization_inputs_capacity_shortage/
```

Each contains `scenario_00/` through `scenario_09/`, with `optimizer_ev_sessions.csv` and `optimizer_grid.csv`. See `load()` in the driver for exact columns. There are 24 hourly grid rows. EV arrival/departure indices must lie in this horizon, with departure strictly after arrival. Original archived scenarios truncate sessions at the horizon.

Scenario IDs 00–03 are planning paths, 04–06 select commitments, and 07–09 are test replay paths. Preserve the splits and paired stress scenarios. A full replay can be expensive:

```bash
python run_section_iv_replay.py --check-only
python run_section_iv_replay.py --output section_iv_replay_results --workers 1
```

Raw capacity and the assumed 1,500 kW floor are separate capacity regimes. The constructed shortage is another control. Three successful test deliveries out of three are descriptive; they do not establish 95% population reliability.

## PINN and later experiments

`battery_degradation_model_pinn.py` includes a synthetic training example; synthetic labels are not independent cell validation.

The later directional PINN drivers additionally import `train_battery_degradation_pinn_temporal_dual_head` from a configured external source directory and load `processed/battery_degradation_pinn_temporal_dual_head_real_calibrated.pt`. This external module and checkpoint are not in the supplied project source. Those experiments cannot be reproduced from this release alone.

Some optional LLM drivers also reference locally generated configuration/response artifacts (including `llm_top_config_gemini`). Inspect their CLI and source before running. Live API calls can incur charges; the quick checks do not call an API. Archived seeds/responses are excluded.

## Exclusions and publication

No raw EV records, grid downloads, third-party references, generated scenario archives, checkpoints, result tables, manuscripts or API responses are uploaded. This avoids implicitly redistributing third-party data and personal session metadata. Obtain the necessary inputs separately and document source/version and processing steps.

The repository has no chosen redistribution license. Select a license only after confirming authorship and institutional/coauthor requirements.
